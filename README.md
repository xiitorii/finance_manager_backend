# Finance Manager

Система управления личными финансами, позволяющая пользователям регистрироваться, аутентифицироваться и управлять своими транзакциями. Проект реализован на основе Spring Boot и предоставляет RESTful API для взаимодействия с данными о финансовых операциях.

## Технологии

Проект построен с использованием следующих технологий:
- **Spring Boot** — основа приложения, обеспечивающая инфраструктуру и автоконфигурацию
- **Spring Security** — защита приложения, управление доступом и аутентификация
- **JWT (JSON Web Token)** — токены для безопасной аутентификации и авторизации
- **PostgreSQL** — реляционная база данных для хранения данных пользователей и транзакций
- **Docker** — контейнеризация приложения и базы данных
- **Flyway** — управление миграциями базы данных
- **MapStruct** — маппинг объектов между слоями приложения (DTO ↔ Entity)

## Особенности

Ключевые особенности и возможности системы:
- **JWT-аутентификация**: Безопасный процесс входа и регистрации с использованием токенов
- **Ролевая модель доступа**: Поддержка различных ролей пользователей с разграничением прав
- **Управление транзакциями**: Полный цикл CRUD для финансовых операций с валидацией и фильтрацией
- **Контейнеризация через Docker**: Легкий запуск приложения в изолированных контейнерах, включая базу данных

## Установка и запуск

Инструкции по локальному запуску приложения:

1. Создайте файл `.env` в корне проекта с переменными окружения:
```
DB_PASSWORD=your_password
DB_USERNAME=postgres
DB_NAME=finance_manager
JWT_SECRET=your_64_character_jwt_secret_key
```

2. Запустите приложение через Docker Compose:
```bash
docker-compose up --build
```

3. Приложение будет доступно по адресу: `http://localhost:8080`

> **Примечание**: Убедитесь, что Docker установлен и запущен на вашей машине.

## API Endpoints

Основные REST-эндпоинты:
- `POST /auth/registration` — регистрация нового пользователя
- `POST /auth/login` — аутентификация пользователя и получение JWT-токена
- `GET /transactions` — получение списка транзакций (требуется аутентификация)

> Примеры запросов и ответов можно найти в документации API (при наличии).

## Настройка базы данных

Проект использует **Flyway** для управления миграциями базы данных. Все SQL-скрипты миграций должны находиться в папке `src/main/resources/db/migration`. При старте приложения Spring Boot автоматически применяет миграции к базе данных PostgreSQL в порядке возрастания версий. Это обеспечивает согласованность схемы БД между разными окружениями.
